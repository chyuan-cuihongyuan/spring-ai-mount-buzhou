# spring‑ai‑mount‑buzhou Agent 生产级中间层需要补全完整功能清单

先明确项目定位：**Harness 是 Spring‑AI 上层运行时中间件、不替换 Spring‑AI，只做代理、管控、观测、流量治理、故障隔离，给业务‑Agent 一层生产运行底座**，下面按照「运行时管控、稳定性、可观测可解释、工程能力、RAG / 工具调用治理、安全权限、运维、多 Agent、高可用、业务适配、扩展插件、压测风控」分层拆解缺失必备能力，附带落地思路。

## 一、Agent 运行时生命周期管控（最基础生产刚需）

> 解决 Agent 启动、暂停、销毁、超时、重试、上下文生命周期混乱问题

1. Agent 实例池与生命周期管理器
   - 单业务 Agent 热加载、动态启停、实例隔离、实例销毁回收上下文、内存释放
   - 支持多租户多业务隔离 Agent 实例，不同业务线程 / 资源隔离
2. 会话‑上下文生命周期管控
   - 会话 TTL、自动过期、会话冻结 / 解冻、上下文快照、上下文裁剪策略（token 阈值自动删减历史对话）
   - 区分临时会话、持久会话、长会话、短会话
3. 全局调用超时、分段超时
   - LLM 调用超时、工具调用超时、Agent 思考链超时、整体会话超时，超时强制中断线程、释放资源
4. 分级重试、熔断、隔离舱（Bulkhead）
   - LLM 异常重试、工具函数失败重试、区分可重试异常 / 不可重试异常
   - 线程舱隔离：单个 Agent 故障不会拖垮全部业务；LLM 服务商故障熔断降级、快速失败
5. 异步任务调度
   - 阻塞型 Agent 任务异步排队、任务优先级、任务取消、延迟执行、定时 Agent 任务

## 二、稳定性增强（保证 Agent 线上不崩、不卡死、不无限循环）

1. 防止 Agent 死循环检测
   - 限定最大思考步数、最大工具调用次数；检测重复思考、循环调用工具，到达阈值强制终止并返回告警
2. Token 硬限流
   - 输入 token 上限、输出 token 上限、全会话累计 token 阈值拦截，防止超长上下文打爆 LLM 和内存
3. 内存与资源监控
   - Agent 线程内存占用、上下文对象大小、缓存占用，超限主动清理上下文、触发告警
4. 多 LLM 服务商负载均衡 & 故障转移
   - 兼容 OpenAI、通义千问、DeepSeek、本地 Ollama；主备切换、负载均衡、服务商自动降级
5. 工具调用容错
   - 自定义工具异常捕获、工具返回结果异常清洗、工具超时兜底返回预设提示、禁用异常工具
6. 幂等控制
   - Agent 请求唯一 ID，重复请求拦截，防止重复调用数据库、支付、第三方接口等高危工具

## 三、可解释性、全链路追踪（生产排查问题核心）

### 3.1 完整 Agent 链路日志

1. 全链路 Trace：请求入参 → 系统提示词 → 每一轮思考 (Thought) → Action 工具调用 → 工具返回结果 → Observation → LLM 输出 → 最终应答完整全流程日志
2. 每一步 token 消耗、耗时、LLM 返回原始报文、耗时、模型名称、温度参数全部持久化

### 3.2 可视化溯源

1. 会话链路树状图、思考链可视化
2. 提示词快照，每一次发给大模型的 Prompt 完整存档，支持回放完整 Agent 执行流程
3. 异常快照：Agent 报错、循环、超时的时候自动保存全部上下文快照用于复现

### 3.3 指标埋点

- 调用成功率、平均耗时、工具调用频次、失败类型分布、token 消耗、会话时长、循环触发次数
- 对接 Micrometer、Prometheus、Grafana 指标上报

### 3.4 会话回放 & 调试模式

- 线上会话 ID 一键回放 Agent 完整思考流程
- 开发环境断点调试 Agent 每一步思考、支持手动拦截修改工具返回结果调试

## 四、提示词 (Prompt) 工程运行时治理

1. Prompt 动态管理中心
   - 数据库存储 Prompt 模板、版本管理、灰度发布、热更新，不用重启服务修改系统提示词
2. Prompt 校验、敏感词拦截、长度校验、模板参数校验
3. 多环境 Prompt 隔离：测试环境、预发、生产区分模板
4. Prompt 缓存、Prompt‑token 压缩优化、自动 Prompt 优化器

## 五、工具调用（Function‑call）管控层

Spring‑AI 自带工具调用，中间层需要叠加管控能力：

1. 工具注册中心、工具开关、黑白名单，业务 Agent 可动态启用 / 禁用工具
2. 工具权限管控：不同会话、不同用户可调用的工具列表隔离
3. 工具入参校验、参数脱敏、入参拦截、出参清洗
4. 工具调用日志、耗时统计、工具熔断、工具降级
5. 工具调用限流：单会话最大调用次数、全局 QPS 限制
6. 工具缓存：相同参数的工具结果缓存，减少重复接口请求

## 六、RAG 检索中间层管控

如果 Agent 依赖知识库检索：

1. 检索参数管控：top‑k、相似度阈值可运行时动态调整
2. 检索结果过滤、去重、文档权限过滤
3. 检索耗时监控、检索失败兜底策略
4. 知识库版本绑定 Agent，不同 Agent 挂载独立知识库

## 七、安全、风控、脱敏、权限体系

1. 输入输出安全检测
   - 输入违禁词、Prompt 注入攻击检测、越狱提示拦截
   - LLM 输出内容合规审核、违规内容拦截、替换屏蔽词
2. 数据脱敏
   - 自动识别手机号、身份证、银行卡、地址，入参脱敏、日志脱敏
3. 用户‑会话‑Agent 权限
   - RBAC 权限模型，用户只能访问指定 Agent、指定工具、指定知识库
4. 水印、溯源标记，LLM 输出嵌入隐形水印
5. 会话数据加密存储、传输加密、敏感上下文禁止打印日志

## 八、可观测、告警、日志持久化

1. 日志持久化：MySQL/Elasticsearch 存储全部 Agent 会话、思考链路
2. 多维度告警：调用失败率飙升、Agent 频繁循环、LLM 超时暴涨、token 消耗超限、敏感请求命中
3. 告警通道：钉钉、企业微信、邮件
4. 慢 Agent 调用追踪，超过阈值耗时自动标记慢请求

## 九、多 Agent 编排与会话管理

1. Agent 路由：根据用户请求自动路由到对应业务 Agent
2. Agent 之间通信、子 Agent 嵌套调用、串行 / 并行 Agent 编排
3. 会话多 Agent 上下文共享、上下文隔离开关
4. 会话多端同步、会话断点续跑

## 十、流量管控、限流、计费、灰度

1. 多层限流：全局 QPS、单用户 QPS、单 Agent QPS、LLM 模型维度限流
2. 流量灰度：Prompt 新版本、新工具、新模型小流量灰度上线
3. Token 用量统计、计费模块、业务部门用量配额、用量超限拦截
4. 流量镜像，线上流量镜像到测试环境复现问题

## 十一、缓存、上下文持久化 & 状态管理

1. 会话上下文支持 Redis 持久化，服务重启之后 Agent 会话不会丢失
2. 状态化 Agent：支持存储 Agent 中间业务状态、变量、临时计算结果
3. 上下文冷热分离，过期会话归档至数据库

## 十二、开发、调试、测试、热更新能力

1. Agent 热重载：Prompt、工具函数、配置修改不需要重启 Spring 服务
2. Agent 单元测试框架：对 Agent、工具、提示词编写自动化用例
3. 仿真测试、批量测试数据集、Agent 通过率评测
4. 沙箱模式：测试环境 Agent 禁止调用真实业务接口，使用 Mock 工具返回

## 十三、降级、兜底策略（生产稳定性重中之重）

1. LLM 全部故障时开启静态兜底应答
2. Agent 思考失败、工具调用失败的分级兜底话术
3. 本地缓存高频问题应答，绕过 LLM 直接返回结果，节省 token、提升速度

## 十四、插件化扩展架构

因为中间层是叠加在 Spring‑AI 上层，必须做到插件可插拔：

- LLM 适配器插件
- 工具插件加载器
- 风控检测插件
- 观测链路插件
- 存储适配器（支持切换 Redis、ES、Mysql）

## 十五、运维后台管理面板

必备可视化后台：

1. Agent 列表、启停、配置编辑
2. Prompt 版本管理
3. 在线会话查看、会话回放
4. 监控大盘：成功率、耗时、Token 消耗、失败排行
5. 工具调用日志、风控拦截记录、告警记录

# 优先级排序（从紧急到次要）

1. **Agent 生命周期管控、超时、熔断、线程隔离、循环防护、Token 上限（稳定性底座）**
2. **全链路思考追踪、会话回放、日志持久化（排查线上问题）**
3. Function‑call 工具管控、黑白名单、参数校验、熔断
4. Prompt 动态热更新、版本管理
5. 安全风控、注入检测、数据脱敏
6. Redis 会话持久化、限流、告警指标
7. 管理后台、多 Agent 编排、灰度、评测平台
