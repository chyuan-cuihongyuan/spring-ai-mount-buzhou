# Spring AI Mount Buzhou（不周山）

挂载在 Spring AI 与业务 Agent 之间的运行时中间层（Harness）——叠加而非替代 Spring AI，让单个 Agent 稳定、可控、可解释地跑在生产里。

## 能力一览

- **渐进式记忆压缩** — 微压缩（工具结果回收，纯内存）+ 九段式结构化摘要 + 动态预算，信息连续降级永不断崖丢弃
- **Spill 溢出保护** — 超大工具返回值自动落盘，上下文只留预览 + 回读路径，模型持 `read_range` 按需回读
- **Span + Event 认知可观测** — 记录模型基于什么证据、做出什么推理；内嵌可视化后台可回放会话、还原每轮实际注入上下文
- **Skill 体系 + MCP 热插拔** — 能力按需加载；工具集配置驱动、运行时热更新
- **并行工具调用** — 虚拟线程 fan-out，按序回注，单工具超时不拖整轮
- **Hook 护栏体系** — 长产物读写护栏、HITL 危险操作人工审核、Hook→state→Attachment 联动闭环
