# Spec 7030 — XxHash64（effort #7030，U31）

> wayfinder map：`.wayfinder/maps/effort-7000.md`（U7261–U7262，impl 2282）。
> 借鉴：Collet xxHash 思想（Kafka/ZSTD 同源）。

## Problem Statement

哈希选型的病：JDK 内建哈希质量不足、SHA 加重负载
——**四累加器条带旋转混合+雪崩终洗面**缺失。

## Solution

`XxHash64`（core/message，静态工具面）：官方质数常量
（模 2⁶⁴ 补码入 long——勘误：初版正数字面量编译失败，
钉住修正）32 字节条带路径+8/4/1 尾路径+雪崩终洗；
官方钉子向量（空/单字符/abc，seed 0）；确定性纯函数；
非加密承诺明示。

## Testing Decisions

- 官方向量三例；stripe 与尾路径镜像一致（0..200 逐长）；
  种子扩散+确定性；fail-fast。

## Out of Scope

- 不做 XXH3；不做流式增量。

## Further Notes

- 与 Crc32C（同包）同族不同面：线性校验码 vs 雪崩哈希。
- 里程碑：U31/50（62%）。
