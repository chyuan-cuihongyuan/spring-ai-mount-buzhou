# Spec 2064 — Z 序曲线（effort #2064，R65）

> wayfinder map：`.wayfinder/maps/effort-2000.md`（T3229–T3230， impl 1615）。
> 借鉴：Morton 码 / Z-order——多维位交织一维化保局部性。

## Problem Statement

多维键（时间 × 租户 / 轮次 × 工具）进一维索引（B 树 / 键序区间扫描
SPI）会丢局部性：拼串序使一维序只按首维聚簇——次维邻点在标量上
相距甚远，多维范围查询无法退化为标量区间。

## Solution

`ZOrderCurve`（core/recovery，纯函数零状态）：

- `encode(x, y)`：位交织——x 占偶数位 y 占奇数位（每维交替贡献，
  int×32 位 → long 64 位恰容）——**格内紧致**（x,y < 2ⁿ → 标量 <
  2²ⁿ——多维子空间落入有界标量段，范围查询变区间）；
- `decode(z)` 互逆（含负值/极值往返）；scalarGap/manhattan 局部性
  对照读数；
- 诚实边界：**逐对紧界不成立**（借位位结构致 Z 形跳变）——语义是
  格内紧致与渐近局部，非任意邻点恒近。

## User Stories

1. 作为索引作者，多维键压成 Z 序标量——区间扫描天然覆盖多维邻域。
2. 作为迁移作者，decode 往返无损——编码可回退。

## Testing Decisions

- 往返（0/0、3/5、负值、int 极值）；手算编码（(1,0)=1、(0,1)=2、
  (1,1)=3、(2,0)=4、(0,2)=8）；位交织结构（3→0b0101）；16×16 格全
  <256（数学可证紧致）；4×4 格极差 <64；scalarGap 对称。

## Out of Scope

- 不做三维+（两维口径）；不做范围查询构造（bigmin/littlemax 优化
  留白）；不接键序区间 SPI（接线归后续轮）。

## Further Notes

- 与键序区间扫描 SPI（#39）/一致性哈希环（2025）互补：扫描原语 ×
  归属原语 × 局部性编码。
