# 611 — 语义缓存维度漂移可见性

> 借鉴：模型漂移可观测惯例（HuggingFace/生产 ML 监控——特征/嵌入漂移计数先行，降级静默是排障黑洞）。
> 来源：F 会话第 12 轮 = effort #600 / [T872](../../.wayfinder/tickets/T872-semantic-drift-shape.md) / [T873](../../.wayfinder/tickets/T873-semantic-drift-verify.md) / impl 464。

## 背景

语义缓存（spec 55）的 cosine 对维度不匹配条目防御性跳过；嵌入模型变更（1536→768 维）后全部旧条目静默失配——命中率塌方无任何信号，排障只剩「命中率莫名归零」。

## 目标

`dimensionMismatches()` 计数 + 首次漂移 WARN（提示模型变更与修法）。

## 非目标

- 不自动清缓存（破坏性动作归运维；新条目自然收敛 + LRU/TTL 淘汰旧条目——用例钉住）。
- 不做跨实例漂移聚合（单进程口径先行）。

## 设计

- 计数粒度 = 每次查询 × 每条不匹配条目；维度检查前移到 cosine 之前。
- WARN 原子去重一次（不刷屏）；观测面 `dimensionMismatches()` 持续可读。

## 测试

3 用例：不匹配计数与跳过不抛 / 同维度不受影响 / 新维度条目自然收敛。

## 兼容性

纯增量（计数器 + getter + 日志）；跳过语义与 spec 55 零变化。
