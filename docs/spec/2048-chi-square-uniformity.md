# Spec 2048 — 卡方均匀性检验（effort #2048，R49）

> wayfinder map：`.wayfinder/maps/effort-2000.md`（T3197–T3198，impl 1599）。
> 借鉴：Pearson χ² 拟合检验（统计学经典）——均匀偏离度可判定。

## Problem Statement

分布均匀性判断散落各处拍脑袋：「桶频数差多少算偏斜」无口径——评估
输出分布（模型回答偏斜）/哈希分桶负载（一致性哈希环）/采样公平性
的偏斜判定需要统计学的标准答案。

## Solution

`ChiSquareUniformity`（core/eval，纯函数零状态）：

- `test(observedCounts)`：χ² = Σ(O−E)²/E（E = 总/k）+ 自由度 k−1 +
  **0.05 显著水平临界值表**（内置自由度 1–20，桶数 2–21）+ 拒绝判定
  （statistic > critical 即拒绝均匀假设）；
- 契约：桶数 ∈ [2,21]、频数 ≥ 0、总量 > 0 fail-fast。

## User Stories

1. 作为评估作者，模型回答五桶分布 χ² 检验拒绝即「回答偏斜」可判定
   ——不拍脑看图。
2. 作为哈希环验证者，负载分桶均匀性有统计口径——临界值表内置免查
   手册。

## Testing Decisions

- 完全均匀 χ²=0 不拒；97:1:1:1 显著拒绝；52/49/51/48 轻波动不拒；
  60:40 手算 χ²=4.0 恰超临界 3.841（公式钉死）；临界值随自由度递增；
  零观测桶合法；畸形五型 fail-fast。

## Out of Scope

- 不做任意分布拟合（均匀口径）；p 值计算留白（临界值判定口径）；
  桶数 >21 查表扩展归后续。
