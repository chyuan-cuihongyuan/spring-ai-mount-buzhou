# Spec 4007 — CRC-32C 校验（effort #4007，R8）

> wayfinder map：`.wayfinder/maps/effort-4000.md`（T6015–T6016，impl 2108）。
> 借鉴：Castagnoli 多项式（iSCSI/ext4/LevelDB/SSE4.2 同款）。

## Problem Statement

传输/落盘完整性需要软件基准口径的强校验——IEEE CRC-32 关键汉明
距弱于 CRC-32C，且 32C 有硬件路径缺**跨平台对账锚点**。

## Solution

`Crc32C`（core/message，纯静态表驱动）：

- 反射算法逐字节查表（多项式 0x1EDC6F41 反射形 0x82F63B78，
  init/xorout 全 1）；
- compute 全量/区间双面；verify 到达校验（相等即真）；
- 标准检验向量锚定（"123456789"→0xE3069283 等）。

## User Stories

1. 作为导出作者，落盘块完整性有软件基准——同输入同输出跨平台。
2. 作为传输作者，单比特翻转必被查出（突发错误强度）。

## Testing Decisions

- 六标准向量（123456789/a/abc/空/32×00/32×FF）；区间=全量、
  子区=拷贝区间；单比特翻转必变 + verify 真假两向；畸形三型
  fail-fast（null/越界/负 off）。

## Out of Scope

- 不做分块流水 update 面（单次 compute 口径）；不做硬件 SIMD
  路径（软件基准即定位）；不做 CRC-64（后续候选）。

## Further Notes

- 与编码件（Varint/EliasGamma/Huffman）成对：编码管紧凑、
  校验管到达一致。
- 里程碑：8/50。
