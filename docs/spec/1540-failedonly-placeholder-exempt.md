# 1540 — FAILED_ONLY 占位的批预算豁免（spec 1526/1527 组合补强）

> 来源：M 会话第 44 轮 = effort #1540（impl 1143）。组合测试（FAILED_ONLY × 批预算）实证缺陷。

## 背景

FAILED_ONLY 反馈策略下成功工具以短占位文本（"[本批有同伴失败：此工具已成功执行…]"，54 字符）回喂；该占位非 isErrorFeedback 格式——批预算截断豁免不命中，实证被截到 0 字符（模型完全丢失该工具已成功的信号，回喂纯截断标记）。

## 目标

占位前缀常量化（responsesForModel 生成 / applyBatchBudget 豁免共用）+ 豁免条件纳入占位前缀。

## 兼容性
